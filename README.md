# Yoru

Личный трекер аниме и сериалов. Приложение на русском языке без этапа сборки и без серверной базы данных.

## Сайт и репозиторий

- Сайт: https://dimanoid007.github.io/yoru-watchlist/
- Исходники: https://github.com/dimanoid007/yoru-watchlist

GitHub Actions проверяет JavaScript, запускает тесты и публикует содержимое `dist/` в GitHub Pages при каждом push в `main`. Публикацию также можно запустить вручную из вкладки Actions, workflow `Deploy GitHub Pages`.

Пути к скриптам, каталогу и изображениям относительные; навигация использует hash-маршруты, поэтому приложение работает в подкаталоге GitHub Pages и не требует серверных перенаправлений.

Коллекции привязаны к адресу сайта. Если вы уже ведёте список на другом адресе, экспортируйте JSON из профиля на старом сайте и импортируйте его на GitHub Pages.

## Запуск

Требуется Node.js 20 или новее.

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Статические файлы находятся в `dist/`.

```sh
npm run check
npm test
```

## Возможности

- Обзор профиля, коллекция с пятью статусами, фильтры по типу и сортировка.
- Поиск аниме в Shikimori, сериалов в TVmaze. Для сериалов каталог лучше ищет по английскому названию.
- Совместные фильтры по типу, нескольким жанрам и диапазону оценок от 0 до 10; сортировка по рейтингу, году и названию. Поиск аниме передаёт жанры и минимальную оценку в каталог. Для сериалов без названия загружается очередная страница каталога TVmaze, поэтому «Загрузить ещё» расширяет подборку; поиск по названию ищет во всём каталоге.
- Страница тайтла: описание, количество вышедших и общее количество эпизодов, длительность, статус и прогресс.
- Каждая отметка серии записывает её длительность на момент просмотра. Для сериалов учитывается длительность конкретного эпизода, если её предоставил каталог.
- Отмена последней серии пересчитывает время. Достижение последнего эпизода завершённого тайтла автоматически меняет статус на «Просмотрено».
- Дневная история, время за неделю и статистика по типам.
- Ручное добавление, профиль, резервное копирование и восстановление JSON.
- Адаптивная вёрстка и управление с клавиатуры.
- Встроенные Kodik и Turbo прямо в карточке тайтла: выбор источника, серии и полноэкранный режим. Отметка выбранной серии и переход к следующей, отмена последней отметки и сохранение выбранного плеера.

## Встроенный просмотр

В карточке тайтла нажмите «Смотреть онлайн». Блок плеера находится под информацией о тайтле; рядом расположены текущая серия, прогресс и кнопка «Просмотрено → следующая». Плеер открывается внутри iframe, без перехода на другой сайт. Интерфейс и подключение Kodik/Turbo адаптированы по [Shiki Player](https://github.com/Gusuder/shiki-player-builds).

Для подбора iframe используется публичный API Kinobox с ID Кинопоиска из каталога; это позволяет получать текущую ссылку Kodik или Turbo. Для Kodik также доступен резервный поиск по идентификатору Shikimori, Кинопоиска или IMDb. Ключ Kodik API из расширения в сайт не переносится. Доступность видео зависит от внешнего источника и сети; при недоступности Turbo можно переключить источник или повторить загрузку.

Серию можно выбрать в списке над плеером. Отметка записывает только выбранный эпизод, не отмечая предыдущие автоматически. Повторная отметка уже просмотренного эпизода не добавляет время. Переключение к следующей серии обновляет iframe; обновление статуса или данных карточки сохраняет существующий iframe. Полноэкранный режим управляется встроенными кнопками выбранного плеера.

Видео не отмечается автоматически: после просмотра нажмите кнопку отметки на этой странице или на закреплённой панели. Приложение хранит выбранный источник и серию в резервной копии вместе с коллекцией.

## Данные

При первом открытии создаётся пустой профиль: без добавленных тайтлов, просмотренных эпизодов и времени просмотра. Старые демонстрационные профили заменяются пустыми с сохранением исходных данных в локальной резервной копии `yoru-library-v1-demo-backup`. Существующие личные коллекции загружаются без изменений. Данные сохраняются в localStorage конкретного браузера на конкретном адресе сайта. Серверной учётной записи и автоматической синхронизации устройств в этой версии нет. Для переноса используйте экспорт/импорт в настройках профиля.

Каталог из 14 тайтлов и их постеры включены в приложение, поэтому можно начать работу без внешнего поиска. Внешние API могут быть временно недоступны; в этом случае отображаются сохранённые результаты и доступно ручное добавление. Неизвестное общее количество показывается как «Не объявлено». Для продолжающегося сериала число известных эпизодов не выдаётся за итоговое число всех будущих серий.

Менять статус и отмечать эпизоды можно независимо: выбор «Просмотрено» сам по себе не записывает время. Для статистики учитываются только явно отмеченные эпизоды. История хранит точную дату и минуты каждой отметки; количество эпизодов определяется по истории.

Метаданные и изображения: [Shikimori](https://shikimori.io), [TVmaze](https://www.tvmaze.com), [лицензия данных TVmaze CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/). Постеры принадлежат соответствующим правообладателям. Скрипт `fetch_catalog.py` обновляет встроенный каталог и изображения через curl.
